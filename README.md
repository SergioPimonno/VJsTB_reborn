# AVE_ToolBox

Настольное приложение (Java 21, Swing) для проектирования LED-экранов и их коммутации: от состава проекта и
расключения питания и сигнала до масок для медиасерверов, расчёта подвеса и транспорта, планера пультовой и пакета
документации для площадки.

## Как устроена работа

Данные организованы как **проект → сцена → экран → кабинеты**; работа идёт по этапам, которые переключаются панелью под
верхним меню:

| Этап | Что делается |
|---|---|
| **Сетап** | Состав проекта, сетка экрана, форма и тип кабинета по ячейкам, прериг (количество кабинетов, вес, мощность, подвес), наземный и напольный конструктив, расчёт подвеса |
| **Питание** | Цепочки расключения по фазам L1/L2/L3, контроль нагрузки на разъём и автомат, общая схема площадки (щиты, дистрибьюторы), блоки питания модульных экранов |
| **Сигнал** | Расключение по портам контроллеров с резервными портами и контролем пропускной способности, приёмные карты модульных экранов, общая схема сигнала, сетевой менеджер (топология, пинг, сканирование IP, конфликты адресов) |
| **Генерация масок** | Канвасы, тестовые маски (Pixel Grid) и пресеты для медиасерверов (Resolume) |
| **Вывод** | Пакет документации: схемы питания и сигнала, блок-схема площадки, спецификации, схема транспорта, раскладки пультовой |
| **Библиотеки** | Кабинеты, оборудование, кабели и переходники, кофры, транспорт, конструктив и прочие общие справочники |

## Возможности

- **Экраны**: сетка кабинетов любых форм (прямоугольные, треугольные, угловые, круглые), свободное позиционирование,
  скрытые ячейки, разные типы кабинетов в одном экране, изогнутые экраны, автоматический расчёт разрешения, габаритов,
  веса и потребления.
- **Цепочки**: построение кликом, протяжкой или стрелками, быстрое подключение областью (8 шаблонов серпантина),
  цепочки на уровне сцены, цвета, многоуровневая отмена.
- **Контроль нагрузки**: предупреждения о перегрузке разъёма, автомата и порта; пакет документации не формируется, пока
  есть неподтверждённые перегрузки.
- **Общая схема площадки**: блоки оборудования с гнёздами и картами, структурированные подписи связей, произвольная
  маршрутизация линий, несколько листов, импорт схемы из yEd (`.graphml`), экспорт в JPEG.
- **NovaLCT**: экспорт расключения в `.scr` (Standard и Complex Screen), в том числе для контроллера с несколькими
  экранами и для модульных экранов с приёмными картами; импорт готовой прописи.
- **Конструктив и подвес**: расчёт наземных башен и напольного каркаса (в том числе изогнутые экраны и раздельные
  башни), подвес методом грузовых площадей, 3D-вид.
- **Калькуляторы**: транспорт (подбор машины и кофров, визуализатор загрузки), видеотайминг (VESA CVT и полоса
  интерфейсов).
- **Планер пультовой** (Инструменты → «Планер пультовой…»): башни, стойки, мебель, станки и мониторы на плане и в видах
  спереди и сверху, трассы кабеля, спецификация и замечания; оборудование можно разбивать на блоки произвольной формы.
- **Библиотеки**: общие и личные, импорт и экспорт в JSON и Excel (шаблон с выпадающими списками), синхронизация с
  сервером и предложения новых записей на модерацию.
- **Команды и облако**: проекты команды хранятся на сервере, роли пользователь, модератор и администратор.
  Приложение полностью работает и без сервера.
- **Прочее**: тёмная и светлая темы, настраиваемые горячие клавиши, встроенное руководство и интерактивные примеры,
  автосохранение, проверка и установка обновлений из приложения.

## Установка

Готовые сборки лежат в [GitHub Releases](https://github.com/SergioPimonno/VJsTB_reborn/releases): архив для Windows
(`AVE_ToolBox-vX.Y-windows.zip`), `.deb` для Linux, `.dmg` для macOS, а также `led-scheme.jar` для запуска на любой
системе с Java 21:

```bash
java -jar led-scheme.jar
```

Обновление версии выполняется из приложения: «Настройки → Обновить версию…».

## Сборка из исходников

Нужны JDK 21 и Maven.

```bash
mvn test
mvn -DskipTests package
java -jar target/led-scheme.jar
```

Команда `package` собирает единый (shaded) jar со всеми зависимостями.

## Хранение данных

Рабочее пространство (общие библиотеки и все проекты) лежит в одном JSON-файле:

```
%USERPROFILE%\.led-scheme\workspace.json   (Windows)
~/.led-scheme/workspace.json               (Linux, macOS)
```

Библиотеки можно отдельно экспортировать и импортировать (этап «Библиотеки»).
