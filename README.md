# LED Scheme Designer

Настольное приложение (Java + Swing) для проектирования схем коммутации
LED-экранов и видеосопровождения: **проект → сцена → экран → LED cabinets**,
с библиотекой кабинетов и схемами расключения питания/сигнала по цепочкам
(daisy chain). Весь интерфейс — внутри приложения; данные хранятся локально.

Веб-интерфейс в этой архитектуре не используется — он планируется отдельно, для
серверного модуля (интеграция с корпоративным приложением, раздача библиотеки
модулей/контроллеров, облачный архив проектов).

## Возможности (текущий этап)

- Проекты → сцены → экраны (создание/удаление, выбор в дереве слева).
- Библиотека LED cabinets (физические ширина/высота, разрешение в px,
  потребление, вес, опционально глубина), общая для всех проектов, с
  импортом/экспортом в JSON.
- Экран собирается из сетки rows × cols кабинетов одного типа; характеристики
  экрана (разрешение, габариты, вес, суммарное потребление, нагрузка по фазам)
  считаются автоматически.
- Схема расключения **питания**: фаза L1/L2/L3 и построение цепочек кликами по
  кабинетам на холсте; кабинеты раскрашиваются по фазе.
- Схема расключения **сигнала**: цепочки кабинетов, опционально с номером порта
  контроллера и пометкой резерва.
- **Отмена последнего действия** (Ctrl+Z, многоуровневая) для операций
  редактирования экрана: цепочки, скрытие кабинета, позиция.
- **Горячие клавиши** (см. ниже) и масштабирование холста (Ctrl+колесо).
- Автосохранение в локальный JSON после каждого изменения.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Z` | Отменить действие |
| `P` / `S` | Режим Питание / Сигнал |
| `N` | Новая цепочка |
| `Enter` | Завершить цепочку |
| `Esc` | Отмена построения цепочки |
| `1` / `2` / `3` | Фаза L1 / L2 / L3 (питание) |
| `Del` | Скрыть кабинет под курсором |
| `Ctrl`+колесо | Масштаб холста |

## Стек и структура

Java 21, Swing + Java2D (UI), FlatLaf (тёмная тема), Jackson (JSON), без БД и
сервера. Сборка — Maven.

```
src/main/java/com/vjstb/ledscheme/
  App.java                 точка входа (main), тёмная тема, запуск окна
  model/                   POJO-модель (Project, Scene, Screen, CabinetType,
                           CabinetInstance, PowerChain, SignalChain, Workspace)
  store/WorkspaceStore     загрузка/сохранение JSON, импорт/экспорт библиотеки
  service/
    AppModel               состояние + все операции + undo + автосохранение
    ScreenLogic            построение/перестроение сетки, статистика, снимок/restore
    ScreenStats            вычисленные характеристики экрана
  ui/
    MainFrame              главное окно, тулбар, горячие клавиши, координация
    SidebarPanel           боковая панель управления
    CanvasPanel            холст: отрисовка сетки и цепочек, клики
    CabinetTypeDialog      диалог кабинета
    Palette, *Renderer     цвета и рендереры списков
src/test/java/...          тесты доменной логики + дымовой тест сборки UI
```

## Хранение данных

Рабочее пространство (библиотека + все проекты) хранится в одном JSON-файле:

```
%USERPROFILE%\.led-scheme\workspace.json   (Windows)
~/.led-scheme/workspace.json               (Linux/macOS)
```

Файл создаётся автоматически при первом сохранении. Библиотеку кабинетов можно
отдельно экспортировать/импортировать в произвольный JSON-файл.

## Запуск в IntelliJ IDEA

1. `File → Open…` → выбрать папку проекта (где `pom.xml`); IDEA распознает Maven.
2. Дождаться загрузки зависимостей (панель Maven → Reload).
3. Запустить класс `com.vjstb.ledscheme.App` (зелёная стрелка Run).

Требуется JDK 21+ (Project Structure → SDK).

## Сборка и запуск из терминала

Исполняемый jar со всеми зависимостями:

```
mvn clean package
java -jar target/led-scheme.jar
```

Тесты (доменная логика + дымовой тест UI):

```
mvn test
```

## Сборка .exe (самодостаточный дистрибутив)

`jpackage` (входит в JDK) собирает нативный лаунчер со встроенной средой
выполнения — Java на машине пользователя не требуется. Сначала `mvn package`,
затем:

```
jpackage --type app-image --name "LED Scheme" ^
  --input target/app-input --main-jar led-scheme.jar ^
  --main-class com.vjstb.ledscheme.App --dest target/dist
```

(`target/app-input` — папка, куда положен только `led-scheme.jar`.)
Результат: `target/dist/LED Scheme/LED Scheme.exe` + папки `app` и `runtime`.
Для установщика (`--type exe`/`msi`) дополнительно нужен WiX Toolset.
