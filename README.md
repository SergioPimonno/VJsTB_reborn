# LED Scheme Designer

Настольное приложение (Java + Swing) для проектирования схем коммутации
LED-экранов и видеосопровождения: **проект → сцена → экран → LED cabinets**,
с библиотекой кабинетов и схемами расключения питания/сигнала по цепочкам
(daisy chain). Весь интерфейс — внутри приложения; данные хранятся локально.

Веб-интерфейс в этой архитектуре не используется — он планируется отдельно, для
серверного модуля (интеграция с корпоративным приложением, раздача библиотеки
модулей/контроллеров, облачный архив проектов).

## Интерфейс: этапы работы

По аналогии со страницами DaVinci Resolve / Pixera работа разбита на этапы,
переключаемые панелью под верхним меню:

- **Сетап** — состав проекта (проекты → сцены → экраны), библиотека кабинетов,
  параметры сетки экрана, базовая сводка прерига (кол-во кабинетов, суммарные
  вес и мощность сцены; точки подвеса — планируются отдельным расчётом).
- **Питание** — холст экрана + построение цепочек расключения питания по фазам
  L1/L2/L3.
- **Сигнал** — холст экрана + расключение по портам контроллера, с пометкой
  резервных (бэкап) портов.
- **Визуализация** — раскладка всех экранов сцены по их координатам (мм) на
  одном холсте, экспорт раскладки в JPEG; генерация масок/пресетов для
  Resolume, Novastar, After Effects — запланирована отдельно.
- **Вывод** — выбор папки и формирование пакета документации проекта (JPEG-схемы
  питания/сигнала каждого экрана + текстовый отчёт).

Верхнее меню (Настройки / Инструменты / Персонализация / Справка) даёт доступ
к расположению файла данных, импорту/экспорту библиотеки, переключению
тёмная/светлая тема и списку горячих клавиш.

## Возможности

- Проекты → сцены → экраны (создание/удаление, списки динамической высоты).
- Библиотека LED cabinets (физические ширина/высота, разрешение в px,
  потребление, вес, опционально глубина), общая для всех проектов, с
  импортом/экспортом в JSON.
- Экран собирается из сетки rows × cols кабинетов одного типа; характеристики
  экрана (разрешение, габариты, вес, суммарное потребление, нагрузка по фазам)
  считаются автоматически. Нумерация кабинетов на схеме — с 1,1.
- **Построение цепочек**: выбор фазы (питание) или порта (сигнал) сразу
  начинает новую цепочку — отдельной кнопки «начать» нет. Кабинеты добавляются
  кликом, протяжкой при зажатой ЛКМ или стрелками клавиатуры; `Esc` завершает
  и сохраняет цепочку. На схеме рисуются стрелки направления расключения.
- **Сигнал**: сетка портов контроллера — ЛКМ начинает цепочку на порт, ПКМ
  переключает пометку «бэкап» (резервный порт не требует расключения кабинетов).
- **Отмена последнего действия** (Ctrl+Z, многоуровневая) для операций
  редактирования экрана: цепочки, скрытие кабинета, позиция.
- Масштабирование холста (Ctrl+колесо), автосохранение в локальный JSON.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Z` | Отменить действие (везде) |
| клик по фазе/порту | Начать новую цепочку (Питание/Сигнал) |
| клик / зажатая ЛКМ / стрелки | Добавить кабинеты в строящуюся цепочку |
| `Esc` | Завершить и сохранить цепочку |
| ПКМ по порту (Сигнал) | Переключить пометку «бэкап» |
| `Del` | Скрыть/показать кабинет под курсором (вне построения цепочки) |
| `Ctrl`+колесо | Масштаб холста |

## Стек и структура

Java 21, Swing + Java2D (UI), FlatLaf (тёмная/светлая тема), Jackson (JSON),
без БД и сервера. Сборка — Maven.

```
src/main/java/com/vjstb/ledscheme/
  App.java                 точка входа (main), тема, запуск окна
  model/                   POJO-модель (Project, Scene, Screen, CabinetType,
                           CabinetInstance, PowerChain, SignalChain, Workspace)
  store/WorkspaceStore     загрузка/сохранение JSON, импорт/экспорт библиотеки
  service/
    AppModel               состояние + все операции + undo + автосохранение
    ScreenLogic            построение/перестроение сетки, статистика, снимок/restore
    ScreenStats/SceneStats  вычисленные характеристики экрана/сцены (прериг)
  ui/
    MainFrame               окно: меню, переключатель этапов, роутинг горячих клавиш
    StageSwitcher            панель переключения этапов
    MainMenuBar              верхнее меню
    ContextBar               компактный выбор проект/сцена/(экран) на этапах
    ChainInteractionController  логика построения цепочки (клик/протяжка/стрелки/Esc)
    CanvasPanel              холст экрана: сетка кабинетов, клики, протяжка
    SceneCanvasPanel         холст сцены: раскладка экранов по координатам
    SchemeRenderer           отрисовка схемы (кабинеты, цепочки, стрелки) — общая
                             для холста и экспорта в JPEG
    PortPickerPanel          сетка портов контроллера (сигнал)
    UiKit, ListSizing, Palette, *Renderer, *Dialog   вспомогательные виджеты
    stage/                   страницы этапов: SetupStagePanel, PowerStagePanel,
                             SignalStagePanel, VisualizationStagePanel, OutputStagePanel
src/test/java/...          тесты доменной логики, контроллера цепочек,
                           экспорта в JPEG, дымовой тест сборки UI
```

## Хранение данных

Рабочее пространство (библиотека + все проекты) хранится в одном JSON-файле:

```
%USERPROFILE%\.led-scheme\workspace.json   (Windows)
~/.led-scheme/workspace.json               (Linux/macOS)
```

Файл создаётся автоматически при первом сохранении. Библиотеку кабинетов можно
отдельно экспортировать/импортировать в произвольный JSON-файл (Сетап или меню
«Инструменты»).

## Запуск в IntelliJ IDEA

1. `File → Open…` → выбрать папку проекта (где `pom.xml`); IDEA распознает Maven.
2. Дождаться загрузки зависимостей (панель Maven → Reload).
3. Запустить класс `com.vjstb.ledscheme.App` (зелёная стрелка Run).

Требуется JDK 21+ (Project Structure → SDK).

## Сборка и запуск из терминала

Исполняемый jar со всеми зависимостями:

```
mvn clean package
java -jar target/led-scheme.jar
```

Тесты (доменная логика, контроллер цепочек, экспорт, дымовой тест UI):

```
mvn test
```

## Сборка .exe (самодостаточный дистрибутив)

`jpackage` (входит в JDK) собирает нативный лаунчер со встроенной средой
выполнения — Java на машине пользователя не требуется. Сначала `mvn package`,
затем:

```
jpackage --type app-image --name "LED Scheme" ^
  --input target/app-input --main-jar led-scheme.jar ^
  --main-class com.vjstb.ledscheme.App --dest target/dist
```

(`target/app-input` — папка, куда положен только `led-scheme.jar`.)
Результат: `target/dist/LED Scheme/LED Scheme.exe` + папки `app` и `runtime`.
Для установщика (`--type exe`/`msi`) дополнительно нужен WiX Toolset.
