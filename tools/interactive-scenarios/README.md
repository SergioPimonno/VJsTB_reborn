# Интерактивные примеры — сборка ассетов

Наполняет синглтон сервера `INTERACTIVE_SCENARIOS` (см. `Scenario` /
`ScenarioListDialog` / `ScenarioPlayerDialog` в клиенте, `ScenarioEditorPanel` в
`ledscheme-admin`) готовым набором из 7 пошаговых экскурсов по этапам работы —
каждый шаг со скриншотом реального UI, часть шагов — с кликабельным хотспотом.

Текстовая основа (заголовки + `bodyHtml`, без картинок) — человекочитаемый
мастер `../../interactive-scenarios.seed.json`. Здесь она обрастает скринами и
хотспотами.

## Конвейер

1. **Скриншоты + координаты кнопок** — JUnit-генератор (не регрессия, гейтится
   флагом; нужен дисплей):

   ```
   mvn test -Dtest=ScenarioShotSpike -Dscenario.shots=true
   ```

   Строит настоящий `MainFrame` с наполненным демо-воркспейсом, проходит по
   этапам/видам, пишет `shots/<этап>.png` и `shots/hotspots.json`
   (относительные 0..1 прямоугольники ключевых кнопок). Каталог можно
   переопределить: `-Dscenario.shots.dir=…`.

2. **Сборка payload** — `python build_full_scenarios.py`: берёт текст из
   `seed.json`, ужимает каждый PNG в JPEG (base64), привязывает картинку к
   каждому шагу и хотспот — к навигационным шагам по таблице `MAP` внутри
   скрипта. Пишет `interactive-scenarios.full.json` (~1.8 МБ, git-ignored),
   авто-подбирая качество JPEG под лимит.

3. **Публикация** — `python push_scenarios.py`: логинится на
   `ledscheme-server` как ADMIN (пароль спрашивается в консоли, не логируется) и
   делает `POST /api/admin/library/singleton/INTERACTIVE_SCENARIOS` — ровно то
   же, что «Импортировать из файла… → Сохранить» в админ-консоли. В конце
   перечитывает синглтон с сервера для проверки.

   Альтернатива без скрипта: открыть `interactive-scenarios.full.json` в
   `ledscheme-admin` (вкладка «Интерактивные сценарии» → «Импортировать из
   файла…» → «Сохранить»).

## Правка содержимого

- Текст шага, порядок, добавить/убрать шаг — в `../../interactive-scenarios.seed.json`.
- Какой скрин/хотспот у какого шага — таблица `MAP` в `build_full_scenarios.py`
  (число кортежей в строке = числу шагов сценария).
- Новый хотспот на другую кнопку — добавить `putHotspot(...)` в
  `ScenarioShotSpike.java` и прогнать шаг 1 заново.
- Демо-воркспейс на скринах (проект/сцена/цепочки/сети/…) —
  `ScenarioShotSpike.buildSampleWorkspace`.
