## ПОСТ 1

🚀 **AVE_ToolBox 2.6**

🧩 **Общая схема**
• Несколько схем на сцену — «Схема:» вверху, кнопки ＋ ✎ ⧉ 🗑
• **Расставить блоки** — одна кнопка раскладывает схему колонками слева направо: серверы → оборудование → контроллеры → конвертеры → экраны
• **Подогнать блоки** — размер под содержимое
• Линии заходят в экраны **снизу** (сторону можно сменить в Предпочтениях)
• Подпись шины теперь по желанию: у гнезда значок «×N» → «Объединить в шину»
• «Шрифт схемы…», зазоры между картами, «Сохранить блок в библиотеку…»

📚 **Оборудование**
• **Серии** (Novastar H, Disguise VFC…): выбрали серию — у модели появились общие карты серии
• Лимиты карт: «Входные 2/4 · Выходные 1/2», больше не добавить
• «Копировать из…» — карты между оборудованием
• **Заменить…** контроллер — новая модель встаёт на место выбранной, в меню только подходящие по портам, расключение переезжает (при нехватке номеров — уплотняется); у H-серии подскажет, сколько карт собрать

🎭 **Маски**
• Растр убран → «Плашка» и «Разрешение»
• «Экран-сетка» (×N), «Свои цвета…»
• Предупреждение, если канвас обрезает маски
• Канвас и маски до **30000 px**, запись по частям с прогрессом

🏗 **Конструктив и пол**
• Изогнутые экраны: вогнутые и выпуклые, раздельные башни по дуге
• Ползунки в 3D: радиус, зазор, число башен
• **Каркас пола**: рамы, стаканы, ножки, кабинеты без опоры; план 2D/3D с правкой кликом

📏 **Подвес и вывод**
• Ширина экрана — по **реально стоящим** кабинетам (в Left 2 было 7 м вместо 6,5 м)
• Спецификация — **файл на каждую сцену**, колонки по схемам
• Таблица экранов: цвета типов, легенда и статистика
• Каждая схема экспортируется отдельным файлом

🛠 Приветствие со страницей «Что нового», лог запуска startup.log, Ctrl+Z возвращает цвета масок и конструктив
🐞 Починено: нижние карточки гнёзд налезали на подписи, спецификация занижала кабели шины (неподписанная линия пучка теперь считается), «Вход связей в блоки экранов» не запоминался

⚠️ **При обновлении**
1. Спецификация больше не общая — по файлу на сцену
2. Проект с несколькими схемами, пересохранённый в старой версии, соберёт всё в одну схему
3. Шины развёрнуты — подписи линий снова видны
4. Если блоки в старых схемах раздуты — «Подогнать блоки»
