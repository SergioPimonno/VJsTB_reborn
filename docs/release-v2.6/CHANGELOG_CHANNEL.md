# Ченджлог AVE_ToolBox 2.6 — для Telegram

Два поста, копировать как есть: `**жирный**` Telegram превращает в жирный при вставке в поле
отправки (если не превратился — выделить заголовки и нажать Ctrl+B). Длина: пост 1 — ~1500 знаков,
пост 2 — ~600 (лимит сообщения 4096). Ссылку на релиз добавить в конец поста 1.

## ПОСТ 1

🚀 **AVE_ToolBox 2.6**

**Добавлено**
• Несколько схем на сцену, «Расставить блоки», «Подогнать блоки»
• Серии оборудования (Novastar H, Disguise VFC…) и лимиты карт, «Копировать из…» — карты между оборудованием
• «Заменить…» контроллер — на его месте, расключение переносится
• «Экран-сетка», «Свои цвета…», канвас и маски до 30000 px
• Изогнутые экраны, раздельные башни, каркас пола с планом 2D/3D
• Спецификация — файл на каждую сцену
• Лог запуска startup.log

**Изменено**
• Линии входят в экраны снизу (сторона настраивается, отдельно для сигнала и питания)
• Шина «×N» — по желанию: «Объединить в шину»
• Растр масок заменён на «Плашку» и «Разрешение»
• Ширина подвеса — по реально стоящим кабинетам
• Таблица экранов: цвета типов, легенда, статистика

**Исправлено**
• Нижние карточки гнёзд налезали на подписи
• Спецификация занижала кабели шины
• «Вход связей в блоки экранов» не сохранялся

⚠️ **Обновляетесь с 2.4 и ниже**
• Библиотека контроллеров больше не отдельная: контроллеры теперь пресеты оборудования сигнала, при первом запуске программа покажет, что будет перенесено, и попросит подтверждение
• Спецификация теперь по файлу на сцену
• Проект с несколькими схемами, пересохранённый в старой версии, соберёт всё в одну схему
