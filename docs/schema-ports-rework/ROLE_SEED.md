# Начальные роли для общей библиотеки (T5.3)

Подготовка данных для координатора — таблица значений `InterfaceType.defaultRole`,
которые нужно проставить в общей библиотеке через `ledscheme-admin` (вкладка
редактора типов интерфейсов). **Публикация — отдельное разрешение пользователя**,
эта задача только готовит список (PLAN.md, задача T5.3).

## Роль по умолчанию для типа интерфейса

| Тип интерфейса (`InterfaceType.name`) | `defaultRole` |
|---|---|
| HDMI | VIDEO |
| DisplayPort | VIDEO |
| SDI | VIDEO |
| DVI | VIDEO |
| USB-C | VIDEO |
| Thunderbolt | VIDEO |
| Ethernet | NETWORK |
| Fiber | VIDEO |
| Genlock | SYNC |
| XLR | AUDIO |
| BNC | OTHER |

Обоснование по каждому — см. таблицу эвристики `PortRoleResolver`
(`service/schemalayout/PortRoleResolver.java`, PLAN.md §2.3): значения выше — те же,
что даёт эвристика без роли в библиотеке, проставляются в саму библиотеку, чтобы
роль была явной (источник 3 в порядке разрешения — `InterfaceType.defaultRole`),
а эвристика (источник 4) оставалась только запасным вариантом для оборудования,
которого ещё нет в библиотеке.

## Переопределение роли гнезда в конкретных пресетах (`CardPort.role`)

Роль гнезда сильнее роли типа интерфейса (источник 2 против источника 3, см.
`PortRoleResolver`) — нужна там, где один и тот же тип интерфейса на разных
пресетах физически несёт разные данные:

| Пресет | Гнездо | `CardPort.role` |
|---|---|---|
| MCTRL4K | RJ45 (OUT) | LED_DATA |
| MCTRL4K | Fiber (все) | LED_DATA |
| CVT4K | Fiber (все) | LED_DATA |

Без этого переопределения `PortRoleResolver.heuristicRole`/`isLedFacingNode`
угадывает то же самое для узлов типа `CONTROLLER`/`CONVERTER`/`SCREEN`
автоматически — переопределение в библиотеке имеет смысл только чтобы роль была
видна явно в редакторе пресета (не курсивом «угадано»), а не потому что без него
разрешение было бы неверным.

## Не проставлять

`CardPort.thru` (транзит) в эту таблицу не входит — авто-угадывание транзита
(`ThruResolver`, состав карты) покрывает контрольные случаи PLAN.md §2.3 без
явных значений в библиотеке; проставлять точечно, только если координатор увидит
неверное авто-угадывание на реальном оборудовании.
